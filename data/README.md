# Data

`trix400.json` and `polymax.json` are digitised from Kodak datasheets by Jan Lohse and
taken from https://github.com/JanLohse/spectral_film_lut (MIT licence, see
`LICENSE-spectral_film_lut.txt`). `tools/extract_data.py` regenerates them from a checkout.

The Tri-X data is the current film (file dated 2007), not the 1960s-70s emulsion. Polymax is a
1998 variable-contrast paper.
